# ecogame
Ajout d'un menu principal et d'un des mini jeu.
Le gameplay initial du jeu est un cycle de mini jeux rapide ( 10 secs max) dont l'objectif est d'atteindre le plus haut score possible
Le mini jeu est celui du barrage, l'objectif est de reboucher des trous placés aléatoirement sur la zone du barrage pour gagner
